The active LCD font assets `lcd18.bin` and `lcd24.bin` were rasterized from
Noto Sans SC Variable (NotoSansSC-VF.ttf). The glyphs use the project's S31A
2-bit alpha format. The source font is available from the Google Fonts
Noto Sans SC family: https://github.com/google/fonts/tree/main/ofl/notosanssc
